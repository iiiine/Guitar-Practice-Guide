# Guitar-Practice-Guide

給沒有老師的電吉他自學者用的練習系統，回答三個問題：**今天練什麼、怎麼練、怎麼用到音樂裡**。

打開就有今日菜單（暖身 → 複習 → 新內容 → 應用），彈完自評「順／卡住／不會」，系統用間隔重複排程下次該練什麼、用多快的速度練。所有資料存在瀏覽器本機，不需要帳號或後端。

## 功能

### 學習
- **樂理五單元**：音名與指板、大調音階、小調五聲、三和弦琶音、藍調音階。從 CAGED 接過來，每單元都分六段：是什麼／聽起來怎樣／跟誰有關／用在哪裡／常見誤區／馬上試試，最後附小測驗與對應練習。
- **原創樂句**：每單元 5 句，都標好調性、和弦時間軸、建議把位與手指。

### 練習畫面
- **動態指板**：當下的音實心最亮，下一個音畫虛線外框，剛彈過的音留下漸淡殘影；推弦、滑音、顫音有專屬標記。
- **音程配色加形狀**：根音方形、和弦音圓形、音階音小圓、經過音菱形，不單靠顏色分辨。
- **標籤切換**：音程（R、b3、5…）／音名（C、D、E…）／兩者。
- **疊層開關**：音階、安全落點、標籤、殘影、下一個音。
- **六線譜窄條**：與指板同步，點音符可以跳到該處；可收合。
- **播放模式**：
  - 示範
  - 跟彈：節拍器、循環、預備拍、每輪自動加速
  - 逐步：按空白鍵前進
- **變化**：轉調（直接選目標調）、換把位、換節奏。變化後的序列必須通過樂句檢查才會播放。

### 練習專區
- **今日菜單**：依 FSRS 排程，安排到期的複習、最多 2 個新項目、1 個變化挑戰和 1 個應用練習，並建議當天的 BPM。
- **練習庫**：所有練習與已解鎖的挑戰。可以依類型、單元、狀態篩選，也可以依課程順序、最需要加強或最久沒練排序。
- **即興練習室**：調 × 和弦進行 × 音階 × 把位自由組合，搭配自動生成的伴奏即興。內建 12 小節藍調、流行四和弦、小調搖滾、ii–V–I 等進行。
- **變化挑戰**：某個樂句練到「順」，而且速度達到目標的 75%，就會解鎖兩個轉調版本和一個換把位版本。
- **藍調曲風區**：12 小節伴奏、獨奏、boogie 節奏吉他。
- **練習紀錄**：每次自評的紀錄、各項目的熟練度與下次複習時間。

### 介面
- 淺色／深色主題（預設跟隨系統，也可手動切換）。
- 快捷鍵：

  | 按鍵 | 功能 |
  |---|---|
  | `Space` | 播放／暫停（逐步模式＝前進） |
  | `↑` `↓` | BPM ±5 |
  | `←` `→` | BPM ±1 |
  | `1`–`5` | 切換疊層 |
  | `N` | 切換標籤 |

## 開始使用

需要 Node.js 20.19 或 22.12 以上。

```bash
npm install
npm run dev            # 開發伺服器 http://localhost:5173
```

| 指令 | 用途 |
|---|---|
| `npm test` | 單元測試（包含所有內容檔的樂句檢查） |
| `npm run check:content` | 只跑內容檢查 |
| `npm run typecheck` | TypeScript 嚴格模式型別檢查 |
| `npm run build` | 型別檢查加打包，輸出到 `dist/` |
| `npm run preview` | 預覽打包結果 |

打包結果是純靜態檔案，可以直接放到 GitHub Pages、Netlify、Cloudflare Pages 等靜態託管服務。

## 技術棧

React 19、TypeScript（strict）、Vite、Tone.js（合成音，不載取樣檔）、tonal（樂理運算）、Zustand、ts-fsrs（間隔重複排程）、idb（IndexedDB）、Vitest、lucide-react。

## 架構

所有練習內容（音階、琶音、和弦轉換、樂句、伴奏）都轉成同一種**事件序列**（`src/sequence/types.ts`），指板、六線譜、聲音只讀這個格式。聲音、節拍器、伴奏、畫面動畫全部以 Tone.js Transport 為唯一時鐘。

```
src/
  theory/     純函式樂理：音名、音階、和弦、音程、角色、和弦進行模板
  sequence/   事件序列型別、規則式生成器、變化（轉調／換把位／節奏）、樂句檢查器
  playback/   播放引擎、伴奏與節拍器（唯一使用 Tone.js 的地方）
  fretboard/  指板 SVG 與視覺狀態推導
  tab/        六線譜窄條
  practice/   FSRS 排程、每日菜單、BPM 建議
  storage/    資料存取介面與 IndexedDB 實作
  content/    課程、樂句、曲風包、變化挑戰
  i18n/       介面文字（zh-TW）
  app/        頁面、版面、路由、設定
```

模組之間的依賴規則（例如 `theory/` 不得引用 React、只有 `playback/` 能引用 Tone.js）由 `src/architecture.test.ts` 自動檢查。

## 撰寫內容

課程與樂句是結構化資料，放在 `src/content/`，可以用 `src/content/dsl.ts` 的小工具撰寫。新增樂句必須通過 `src/sequence/checker.ts` 的檢查：

- 音都在音階內（刻意使用的半音要標 `chromatic: true`）
- 強拍（第 1、3 拍）落在和弦音
- 結尾回到和弦音或根音
- 同一手型的品格跨度不超過 4 格（換把位要在換位的音標 `shift: true`）
- 手指編號合理
- 經過音不放長音、不放在句尾

只收原創樂句，不轉錄或改寫既有歌曲。

## 測試

- 單元測試涵蓋樂理、生成器、檢查器、排程、儲存層與所有內容檔。
