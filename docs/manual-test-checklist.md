# 播放同步手動測試清單

自動測試無法驗證「聽到的」與「看到的」是否一致，每次改動 `playback/`、`fretboard/`、`tab/` 後手動跑一次。

## 準備
- `npm run dev`，用桌面 Chrome 開啟，戴耳機。

## 示範模式
- [ ] 藍調曲風區 →「12 小節獨奏」→ 播放：指板實心音亮起的瞬間與聽到的吉他音一致（無明顯先後）。
- [ ] 六線譜播放線與指板當下音同步；翻頁發生在小節線。
- [ ] 推弦音（第 3 小節 1 弦 8 品）顯示上彎箭頭，聲音確實上揚半音。
- [ ] 右側欄「目前和弦」在伴奏換和弦的同一拍切換；「下一個和弦」提前預告。
- [ ] 安全落點隨和弦改變（A7 → D7 時落點換位置）。
- [ ] 調 BPM（↑↓、←→、滑桿）時聲音與畫面一起變速，不漂移。
- [ ] 循環 1–2 小節：回到開頭時聲音與畫面同時跳回。

## 跟彈模式
- [ ] 預備拍：先聽到 4 下節拍器、位置顯示倒數，然後才開始。
- [ ] 循環第二輪起沒有預備拍。
- [ ] 「每輪 +2」：每輪 BPM 增加，且不超過目標 BPM。
- [ ] 節拍器重拍（第 1 拍）音較高，對齊伴奏大鼓。

## 逐步模式
- [ ] Space／→ 前進一個音並發聲、← 後退；伴奏不播放。
- [ ] 點六線譜上的音符：跳到該音並發聲。

## 其他
- [ ] 第 1 課「找出所有的 C」：指板自動追焦，視窗平滑移動；上方迷你指板的框跟著移。
- [ ] 數字鍵 1–5 切換疊層，重新整理後設定保留。
- [ ] 自評「順」後到練習紀錄頁看得到紀錄；重新整理後仍在（IndexedDB）。
